# 📦 تطبيق جرد المخزون للموبايل (APK + Web)

## خطوات بناء ملف الـ APK على GitHub:
1. فك الضغط عن الملف المضغوط وارفع محتوياته مباشرة داخل مستودع (Repository) على GitHub.
2. ادخل على تبويب **Actions** في المستودع وستجد عملية **Build Android APK** تعمل تلقائياً.
3. بعد انتهاء البناء وظهور العلامة الخضراء، حمّل ملف **Inventory-App-APK** من قسم **Artifacts** وثبّته على هاتفك.
